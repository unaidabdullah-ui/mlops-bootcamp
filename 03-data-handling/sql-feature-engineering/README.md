# 📊 SQL Data Cleaning & Feature Engineering Pipeline (MLOps Style)

This project demonstrates advanced SQL skills used in real-world ML pipelines — including data cleaning, preprocessing, feature engineering, and analytics for downstream Machine Learning models.

## 🚀 Key Features
- ✔️ End-to-end SQL data preparation pipeline  
- ✔️ Data cleaning & missing value handling  
- ✔️ Advanced feature engineering (categorical, numerical, date-based)  
- ✔️ Window functions for rolling statistics  
- ✔️ Views & materialized views for ML-ready datasets  
- ✔️ Performance optimization through indexing  
- ✔️ Analytics & monitoring queries  
- ✔️ MLOps-style modular SQL scripts
